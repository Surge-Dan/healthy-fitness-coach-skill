# 证据感知的联网研究

个人训练日志分析默认不联网。仅在用户要求当前研究、博主主张、产品/API 变更、提供网页，或当前事实会实质改变答案时联网。开发期可使用agent-reach的公开网页/B站/YouTube路由和agent-browser做只读核查；这些工具不属于Skill运行时依赖，也不把Cookie、爬虫或反爬逻辑打包进仓库。能力是可选的：有可用浏览/检索能力时，优先抓取已知公开页面，再用搜索发现来源；没有能力时说明证据边界，不把WebSearch、WebFetch或MCP说成保证存在的依赖。

优先原始研究、系统综述、指南和官方文档。博主/创作者内容只能标为经验层证据，应与更高等级证据交叉核对。继续复用 `creator-cards.md` 的可复用原则、适用条件、执行方法、风险、来源映射和冲突裁决；不要模仿人格，也不要复制课表模板。

对小红书等登录受限平台，先在存在时使用已安装且获授权的连接器或用户授权浏览器；不具备条件时接受截图或粘贴文本。绝不绕过登录、验证码、robots或反爬限制，也不构建爬虫。页面/创作者不可访问时，说明已验证和未验证的内容，不能虚构“蒸馏结论”。具体状态记录在`references/research-ledger.md`；视觉方法记录在`references/visual-reference-ledger.md`。
