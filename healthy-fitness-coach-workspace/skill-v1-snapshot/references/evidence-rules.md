# 证据权重与冲突裁决

## 四层权重

1. **健康硬约束**：公共卫生指南、专业组织指南和同行评议共识。决定适用范围、安全门和普通成人基线。
2. **决策层**：长期从事训练科学、行为改变或负荷管理的研究者/专业团队。用于选择训练量、强度、恢复和调整策略。
3. **专业转译层**：能把研究解释为训练语言的创作者。用于理解概念与生成易执行说明，不单独覆盖上层证据。
4. **执行体验层**：擅长跟练、动作提示、低门槛启动和有限器械方案的创作者。用于改善执行体验，不决定医疗边界或普适处方。

冲突时依次服从：健康硬约束 → 与当前用户最匹配的决策规则 → 专业转译 → 执行体验。名气、播放量、身材和表达自信度不提高证据等级。

## 常见冲突

### 跟练与系统力量计划

跟练适合启动、轻有氧、恢复和最低任务；长期力量与增肌依赖可记录、可渐进的阻力训练。不要二选一，按任务分工。

### 全身、二分化与三分化

由每周天数、肌群频率、恢复和依从性选择。普通新手优先简单结构，不继承博主个人分化。

### 是否力竭

大多数正式组保留约 1～3 RIR。安全器械/单关节动作可偶尔接近力竭；高疲劳复合动作不频繁力竭。动作学习阶段先校准技术和余力判断。

### 有氧是否妨碍增肌

有氧与力量都服务健康。根据主目标管理顺序、剂量和下肢疲劳，不笼统禁止有氧。

### 疼痛时休息还是继续

先筛查红旗。无红旗的一般不适可尝试负荷调整并观察 24～48 小时；持续恶化或影响日常功能时停止自动调整并转介。不远程诊断。

### 精确计算与柔性饮食

按用户追踪意愿和饮食关系，在精确、简化、习惯模式中选择。连续趋势高于单日数字。

## 基础来源

- [WHO 身体活动指南](https://www.who.int/publications/i/item/9789240015128)：成人有氧与肌力活动基线。
- [ACSM 2026 阻力训练指南更新](https://acsm.org/resistance-training-guidelines-update-2026/)：一致性、个体化、训练频率和非必要复杂性。
- [WHO 健康饮食](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)：平衡、多样、限制极端饮食。
- [ISSN 蛋白质立场声明](https://jissn.biomedcentral.com/articles/10.1186/s12970-017-0177-8)：健康运动人群蛋白质一般参考。
- [AASM 成人睡眠建议](https://aasm.org/advocacy/position-statements/adult-sleep-duration-health-advisory/)：规律睡眠至少 7 小时的一般建议。

## 来源记录规则

知识条目记录：来源与发布日期、内容摘要、可复用原则、适用条件、建议参数、证据等级、风险/停止/转介条件、商业利益或身份自述、冲突、最后复核日期。

优先创作者本人官网、官方账号、大学/团队页面、指南和论文。平台简介及个人身份声明按自述处理；未独立核验的信息不升级为确认事实。公开视频或页面无法完整访问时，只蒸馏可核验的公开标题、简介、文本和已访问内容，不暗示逐条观看或转录。

## 对外表达

- 默认解释当前建议的适用理由，不罗列人物名单。
- 用户询问依据时，说明证据层级并给直接链接。
- 区分事实、一般参考、条件性建议和推断。
- 不复制付费课程、完整课表或受版权保护的长篇内容。
- 证据变化时保留复核日期，先更新硬约束，再更新人物卡。
