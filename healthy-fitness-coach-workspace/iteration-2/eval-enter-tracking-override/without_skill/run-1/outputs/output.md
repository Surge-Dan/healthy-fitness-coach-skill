# 跟练模式：先完成第一组

我们现在不展开 3 天计划，先做今天第一组。开始前只确认一件事：现在有没有胸痛、异常气短、晕厥/明显头晕、进行性麻木无力，或急性外伤？如果有，先不要训练并及时获得医疗评估。

如果没有这些情况，第一组做 **高脚杯深蹲**：

- 目标：8 次，保留约 3 次余力（RIR 3）。
- 先选一个你能稳稳完成 8 次、不会动作变形的轻重量；不确定就先徒手做 8 次作为试组。
- 要点：脚掌稳稳压住地面，膝盖跟随脚尖方向，下降到你能控制且舒适的深度，再平稳站起。
- 休息：做完后休息约 2 分钟。

完成后只回复我四项：用了什么重量、做了几次、还剩几次余力、有没有不适。我会据此带你决定下一组，不会假定已经保存任何记录。
