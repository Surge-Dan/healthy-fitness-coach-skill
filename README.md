Healthy Fitness Coach面向18～55岁的健身新手与普通进阶者。它不追求夸张的肌肉、极端减脂或危险训练，而是根据真实目标、时间、器械、恢复和训练数据，给出可执行、可解释、能长期坚持的建议。

> 健身建议不止是“今天练什么”，还应该回答：是否适合你、如何记录、怎样判断有效、什么时候需要调整。

## 适用于哪些运动

Healthy Fitness Coach不是只服务于“健身房撸铁”。它按训练目标和负荷类型工作，适合以下常见场景：

| 运动类型 | 可以解决的问题 | 常见例子 |
| --- | --- | --- |
| **阻力/无氧训练** | 增肌、力量、动作执行、训练量和渐进超负荷 | 杠铃、哑铃、器械、拉力器、自重、徒手力量 |
| **居家与轻器械训练** | 时间短、器械少、出差或恢复期的最低有效训练 | 弹力带、壶铃、瑜伽垫、跟练、全身循环 |
| **有氧基础** | 心肺健康、减脂期活动量、恢复和日常耐力 | 快走、慢跑、骑行、游泳、划船机、椭圆机 |
| **节奏与间歇** | 提高持续配速、心肺能力和高强度耐受 | 节奏跑、坡走、短间歇、HIIT、划船间歇 |
| **功率与综合体能** | 爆发力、协调、力量与心肺的组合 | 跳跃、投掷、短冲、体能循环、混合训练 |
| **活动度与恢复** | 久坐、训练前准备、低强度恢复和动作范围管理 | 动态热身、轻度活动度、拉伸、恢复日 |

它不用于疾病诊断、专项康复、妊娠产后处方、竞技备赛、PED使用、脱水减重或极端减脂。出现胸痛、晕厥、异常心悸、轻微活动即明显气短、进行性麻木无力等情况，应停止自动训练建议并寻求专业评估。

## 给新用户：只需要说一句话

安装Skill后，不需要进入仓库，也不需要安装Node或运行命令，直接对Agent说：

```text
我想开始健身，帮我制定一个适合我的训练计划。
```

如果你已经在使用训记：

```text
我想连接训记。
```

确认后，把训记官方导入/导出说明直接复制给Agent，或者发送截图，并提供你的Open API Key。Skill会根据官方说明识别接口、读取方式和返回格式；凭据只用于本地连接，不会写入仓库、报告、Markdown或回复内容。

连接成功后可以继续说：

```text
分析我最近4周的训记数据，生成趋势面板。
分析今年的训练数据，生成一张带图表的年度报告。
把今天的训练记录整理成适合写回训记的格式，先给我预览，不要直接写入。
```

## ABCDE健康训练闭环

| 环节 | 含义 | Skill会做什么 |
| --- | --- | --- |
| **A｜Assessment** | 评估 | 了解目标、经验、时间、睡眠、营养与安全风险 |
| **B｜Building plan** | 建立计划 | 设计符合频率、器械、时间和恢复能力的训练安排 |
| **C｜Coaching** | 执行辅导 | 提供热身、动作要点、组次、强度、休息和替代动作 |
| **D｜Data review** | 数据复盘 | 分析训练频率、训练量、部位覆盖、动作表现和连续性 |
| **E｜Evolution** | 持续调整 | 依据表现、主观用力程度、体重和反馈逐步调整计划 |

## 知识来源与蒸馏方法

Skill当前维护25个中外专业来源卡。它们不是“名人推荐榜”，也不是把任何人的完整课表复制进来，而是提炼每个来源在特定领域中可复用的决策原则，并记录适用条件、证据等级、商业披露和风险边界。

### 中文创作者与执行体验

谭成义、帅soserious、北美运动学博士Bruce_PhD、周六野Zoey、凯圣王、Erik埃里克。

主要贡献：降低训练启动门槛、改善动作执行、适配有限器械、解释RPE/RIR和帮助普通人建立长期习惯。它们属于执行体验或专业转译层，不能替代指南和原始研究。

### 力量、阻力与肌肥大

Pamela Reif、Jeff Nippard、Eric Helms/3DMJ、Greg Nuckols/Stronger by Science、Mike Israetel/Renaissance Periodization、Brad Schoenfeld、Menno Henselmans、Chris Beardsley。

主要贡献：训练量、次数范围、休息、接近力竭、动作选择、渐进超负荷、周期化和疲劳管理。输出时优先使用可记录的训练变量，不把“泵感”“酸痛”或单个机制解释当成长期效果证明。

### 有氧、耐力与综合体能

Andy Galpin、Stephen Seiler、Dr. Stacy Sims、Jason Koop。

主要贡献：有氧基础、强度分布、耐力负荷、女性运动生理、力量与有氧并行以及恢复管理。Skill不会机械套用“80/20”或精英运动员训练量，而是根据用户频率、目标和恢复能力缩放。

### 疼痛、回归与训练边界

E3Rehab、BarbellMedicine、GregLehman。

主要贡献：红旗筛查、疼痛教育、负荷调整、动作变式和停训后的渐进回归。无红旗的一般不适可以尝试小幅调整；持续恶化、影响日常功能或出现神经症状时转介，不做远程诊断。

### 营养与行为改变

Sohee Carpenter、Layne Norton、Alan Aragon、Danny Lennon/Sigma Nutrition。

主要贡献：能量平衡、蛋白质、饮食依从性、补剂边界、研究质量和不确定性表达。优先建立可持续饮食和趋势反馈，不用极端断食、补剂堆叠或单一食物神话替代基本功。

最终裁决顺序是：健康指南与安全边界 → 原始研究和系统综述 → 专业团队与研究转译 → 创作者执行经验。来源卡的完整记录见[`creator-cards.md`](healthy-fitness-coach/references/creator-cards.md)，有氧/阻力/功率/间歇/混合训练的编排规则见[`training-domains.md`](healthy-fitness-coach/references/training-domains.md)。

## Skill如何工作

1. **先筛查安全边界**：确认年龄、症状、疾病、近期手术或急性外伤；遇到红旗信号时停止自动处方。
2. **再识别训练任务**：区分增肌、力量、减脂、心肺、耐力、动作学习、恢复或混合目标。
3. **按领域加载知识**：根据任务读取对应的训练编排、动作、营养、恢复、证据和来源卡，而不是一次性套用整套课表。
4. **输出可执行方案**：给出动作/方式、组次或时长、强度、休息、替代方案、最低有效版本和进阶条件。
5. **用数据闭环调整**：结合训练记录、RPE/RIR、完成率、体重趋势、睡眠和不适反馈，每轮只调整少量变量。

用户可以选择持续对话，也可以直接要求生成Markdown计划、周/月复盘、年度趋势报告或社交分享图。

## 核心能力

### 🧭个体化训练规划

根据增肌、减脂、体态改善或综合健康目标，结合每周可用时间、训练场地、器械和经验，生成可执行的训练安排，并提供进阶、降阶和动作替代方案。

### 🏋️今日训练助手

从热身开始，按训练顺序给出动作、组次、重复次数、强度区间、休息时间和技术提示。训练中可以根据疲劳、器械占用、动作反馈和疼痛信号即时调整。

### 📊训练数据分析

支持手工日志、导出文本和训记数据，分析训练频率、训练容量、部位分布、有效组、重量与重复次数变化、训练间隔、连续性和潜在过度训练信号。

### 📈趋势面板

生成本地自包含HTML面板和可嵌入Markdown的SVG图表，展示训练天数、训练量、周频率、部位分布、主动作表现和全年训练热力图。

### 📚训练知识库

内置25个中外专业来源蒸馏卡，并按证据层级区分指南、研究转译、专业团队和执行体验。知识库同时覆盖有氧基础、阈值/节奏、高强度间歇、阻力/无氧、力量、肌肥大、功率、混合训练、恢复疼痛、女性运动生理和运动营养。来源卡只提炼可复用原则，不复制个人课表；与指南或用户反馈冲突时，以安全边界、适用条件和连续训练数据为准。

### 🎨报告图与分享图

支持1:1、9:16和3:4三种输出比例，报告图可选择完全不同的视觉布局：

| 布局 | 设计语言 | 适合场景 |
| --- | --- | --- |
| `rich`丰富信息图 | 中文衬线标题、趋势线、雷达图、全年月历热力图、精细网格 | 月报、年报和训练复盘 |
| `minimal`极简分享图 | 深色海报、大数字、非对称几何色块、全年连续热力轨道 | 社交媒体和训练战绩分享 |

无照片时，数据报告支持五套配色主题：酸性夜场、钴蓝珊瑚、紫外荧光、纸张黑墨、熔岩钢板。用户可以直接说：

```text
用丰富信息图布局、纸张黑墨配色，生成今年的3:4训练报告。
用极简分享图布局、钴蓝珊瑚配色，生成最近30天的9:16训练战绩卡。
```

用户上传照片时，Skill会先提取色彩、明暗、纹理、构图、边缘节奏和留白，再提供三种照片优先模式：

- **抽象拼贴档案**：提炼照片中的色块、裁切和几何关系，生成具有个人视觉DNA的拼贴图。
- **训练战报杂志**：保留照片叙事感，加入训练数据、标题和编辑部式标注。
- **材质化数据海报**：提炼照片纹理与色彩，将训练数据融入材质、肌理和非对称版式。

## 训记数据闭环

训记接入采用本地优先和用户确认机制：

1. **读取**：按日期或日期范围调用训记导出接口，并缓存返回结果，避免同一天重复请求。
2. **分析**：保留训练ID和训练时间，解析动作、组次、重量、次数和有氧指标。
3. **预览**：写回前检查日期一致性、记录数量、字符长度和ID是否保留。
4. **写回**：用户明确确认后，按训练ID调用upsert接口，以服务端返回的`res`作为最终缓存结果。

写回是按训练ID更新或新建，不会整天覆盖删除；未出现在本次`res`里的历史训练不会被自动删除。

## 使用方式

### 独立Skill

适合不需要连接健身App的场景。安装[`healthy-fitness-coach/SKILL.md`](healthy-fitness-coach/SKILL.md)对应的Skill，直接通过对话提供个人情况、训练目标或训练日志即可使用。

可直接分发的Skill包：[`dist/healthy-fitness-coach.skill`](dist/healthy-fitness-coach.skill)

独立模式支持：

- **持续对话**：边训练边询问，实时调整当天安排。
- **Markdown交付**：一次性生成训练计划、周期复盘或可保存的分析报告。

### 连接训记

普通用户只需要在Agent中表达“我想连接训记”，再提供官方调用说明和Open API Key。可以复制文字，也可以发送截图；不需要单独安装Plugin或运行命令。

### CodexPlugin高级模式

如果希望长期在本机自动读取训记，可选安装[`healthy-fitness-coach-plugin/`](healthy-fitness-coach-plugin/)。插件提供本地训记MCP连接器、加密凭据存储、日期范围读取、趋势分析和确认后写回，普通用户不需要使用这条路径。

## 数据与安全

- 训练缓存、个人训练数据、报告预览和运行日志只保存在本地，不提交到GitHub。
- API Key使用本机安全凭据存储，不写入项目代码、README、Markdown或生成报告。
- 分析报告默认不嵌入用户原图；只有用户明确要求照片分享图时才保留照片像素。
- 出现胸痛、晕厥、异常心悸、轻微活动即明显气短、进行性麻木无力等红旗症状时，停止生成训练处方并建议寻求专业评估。
- 本项目不能替代医生、康复师或营养师的诊断与治疗。
