# 手机交互与训练闭环优化

本轮实现完成；未进行真实训记账号或手机真机验证。

## 变化

- 连接前判断工具与受保护凭据能力；手机无连接器可导入文本、文件或截图，不再索取聊天 Key。
- 连接、知识问答、分析、写回、接续摘要导出和恢复分别路由。
- 入口与准备度共享安全判断，否认症状不误触红旗，历史情况先澄清。
- 最近七天缓存满五分钟更新；补录支持指定日期/范围刷新。
- 写回预览绑定账号与内容，十分钟过期；结果未知先核对，服务端成功但缓存失败不重发。同批提交日志在重启后继续生效。
- 手机优先可读摘要；接续摘要具备版本、有效期、冲突检测和当前版本指针，不承诺自动云同步。
- 新增六类场景回归及真实对话验收表，保留真实用户指标的待测状态。

## 升级

独立 Skill 使用 dist/healthy-fitness-coach.skill。连接器修复需同时升级 Plugin，完整包为 dist/healthy-fitness-coach-plugin.zip，解压后按 Plugin README 初始化并刷新宿主。

Plugin 版本 0.3.0，MCP 版本 2.0.0。写回接口有兼容性变化：调用者必须先预览，再提交相同内容、confirm 和 preview_id；不能继续使用旧版只有 confirm 的调用。新增核对工具只在用户确认未写入后清除本地提交锁。
