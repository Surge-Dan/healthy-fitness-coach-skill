# 健康健身教练 Skill 实施计划

## 目标

按照已批准的分层单 Skill 规格，生成可验证、可评审、可打包的 `healthy-fitness-coach` V1。

## 执行顺序

1. 先建立结构、安全与内容完整性测试，并确认测试因目标目录不存在而失败。
2. 使用官方 `init_skill.py` 初始化 Skill 和 UI 元数据。
3. 写入精简入口、九个按需知识库、三个输出模板和评测集。
4. 运行本地验收测试、官方 `quick_validate.py`、占位符与链接检查。
5. 用代表性用户场景做有 Skill/无 Skill 对照，优先审查安全关键项。
6. 聚合结果并用官方评测查看器生成静态评审页。
7. 修复关键问题、重新验证、打包并提交。

## 完成定义

- 目标文件齐全，`SKILL.md` 少于 500 行，全部 reference 可从入口直接发现。
- 15 个来源均有可追溯知识卡，并按四层证据权重裁决。
- 至少 6 个普通场景及 6 个安全对抗场景进入评测集。
- 本地验收和官方校验全部通过，安全关键失败数为 0。
- 输出 `.skill` 安装包和静态评审页面。
