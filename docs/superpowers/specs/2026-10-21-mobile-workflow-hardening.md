# 手机交互与训练闭环优化

依据已批准的七项审查建议实施，不新增云服务。

1. 连接前识别连接器、受保护凭据入口及文件能力；手机默认支持人工导入，不索取聊天 Key。
2. 将连接、知识问答、分析、写回区分；安全判断共享实现，否定不触发，历史或语义不明先澄清。
3. 支持指定日期/范围刷新；近期七天缓存过期后更新，保留来源时间和失败降级说明。
4. 写回预览绑定内容与账号、限时有效；提交后区分未提交、已确认、结果未知，阻止同预览重复提交，缓存失败不伪装成服务端失败。
5. 手机/无文件环境默认短摘要；建立可携带训练摘要和当前版本指针，恢复时确认时效和冲突，不声称自动跨设备同步。
6. 增加真实场景回归、真实对话验收表和指标定义；没有真实模型/手机运行数据时不宣称体验验证通过。
7. 同步 Plugin 副本、重建分发包并运行适用测试。

验收：无网络工具仍可导入；否认胸痛仍正常路由；补录历史可刷新；未知写回不自动重试；训练摘要可恢复；15分钟场景可选最低版本并记录反馈。
