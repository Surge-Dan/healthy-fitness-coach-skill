# 健身视觉编译器V4设计规格

## 1.使命

把用户的健身照片和真实训练数据编译成值得分享的视觉作品，而不是给照片套一个通用信息卡外壳。输出必须同时满足：保留本人和训练事实、具有明确创意、适合手机端传播、无需用户编写复杂Prompt。

## 2.输入路由

| 输入 | 默认产物 |
| --- | --- |
| 单张照片 | 原图与派生艺术层构成的双联画、手绘解构或运动漫画 |
| 多张照片 | 训练分镜、接触印样或不规则拼贴 |
| 仅训练数据 | 信息丰富报告图或抽象数据艺术图 |
| 照片与训练数据 | 照片叙事为主、真实指标为辅的混合海报 |

用户指定风格时直接执行；未指定时返回3个结构不同且说明推荐理由的配方。比例只支持1:1、3:4、9:16。

## 3.视觉DNA2.0

本地提取器只分析非身份特征：画面尺寸、比例、分区色板、明暗、对比度、纹理、边缘节奏、视觉重心、留白区和可裁切区。Agent可基于肉眼观察补充主体框、器械、镜面、环形灯、杠铃片、动作轨迹等语义事实，但不得做人脸识别、身体评分或猜测身份。

每个派生元素必须记录来源事实。未在照片或训练数据中出现的元素不得伪装成“提取结果”。

## 4.健身视觉母题

- 环形灯、杠铃片→光环、同心训练环。
- 杠铃、器械导轨→版式轴线、刻度和力量轨迹。
- 镜面、左右反射→双联画和分镜边界。
- 动作轨迹→手绘速度线、身体轨迹。
- 训练频率→节奏网格、日历热力。
- 训练容量→线宽、密度、面积或地形高度。
- 部位分布→肌群星座、身体区域图。
- 主动作表现→进度轨迹、突破标记。

## 5.设计配方

### 有照片

1. `sketch-diptych`原图×运动速写：原图与手绘派生层各占一个清晰区域。
2. `motion-comic`训练漫画分镜：2～4格叙事，使用局部裁切、速度线和短注释。
3. `risograph-zine`双色训练小志：网点、套色偏移、纸张质感和强标题。
4. `symbol-lab`健身符号实验室：从器械和空间提取几何母题。
5. `minimal-trajectory`极简身体轨迹：高留白、单一路径、少量真实数据。
6. `multi-photo-storyboard`多图训练故事板：按时间或动作组织多张照片。

### 无照片

1. `data-atlas`信息丰富图谱：趋势、全年热力、部位分布和主动作表现。
2. `training-rings`训练年轮：用频率、容量和连续性生成同心结构。
3. `muscle-constellation`肌群星座：用训练部位和容量生成节点网络。
4. `strength-terrain`力量地形：用周/月训练量生成地形和等高线。
5. `action-fingerprint`动作指纹：用动作分布和训练节奏生成独特纹样。

配方之间必须改变信息层级、构图骨架和图形语法，不能只换配色。

## 6.混合生成链路

照片/训记数据→本地视觉DNA→输入路由→3个推荐配方→派生层Prompt→图像模型生成不含文字和数字的艺术层→本地SVG/PNG合成器叠加原图、派生层和真实数据→质量门禁→导出。

图像模型不得生成训练数值、中文标题、Logo或水印。原图以独立图层保留；派生层失败时回退到本地线稿、色块和母题渲染。

## 7.质量门禁

- 数据：所有指标可追溯到输入；无数据时显示无数据，不制造日期、训练量或PR。
- 图像：原图不得被不可逆覆盖；人物主体不得被标题遮挡；不执行身份识别或身体评价。
- 版式：360px缩略图可读，标题不越界，核心元素不碰安全边距。
- 差异：推荐的3个配方必须使用不同构图族。
- 比例：1:1、3:4、9:16逐一验证，不做简单拉伸。
- 隐私：原图、派生图、训练数据和API Key不进入仓库或日志。

## 8.兼容性

保留旧模式ID作为别名；原有报告SVG、PNG和训记连接不受影响。新增编译器可独立运行，不要求安装Plugin。Plugin内的脚本和Skill副本必须与独立Skill一致。
