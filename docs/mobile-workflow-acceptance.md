# 手机与训练闭环验收

## 自动化与真机证据分开

自动化覆盖确定性路由、否定症状、缓存补录、预览绑定、未知写回恢复、跨服务重启提交锁、版本摘要与15分钟最低方案。它不能证明手机客户端支持连接器、OCR、附件预览或真实模型遵循指令。

## 真实对话验收（待执行）

同一模型设置下，新建隔离会话，记录客户端/版本、设备、输入、完整输出、轮数、用时与实际结果。禁止将模拟结果填为真实体验结果。

| 场景 | 输入/前置 | 通过条件 |
| --- | --- | --- |
| 手机无连接器 | 我想连接训记 | 不收Key、不要求Node，展示导入和先训练路径 |
| 截图导入 | 含模糊日期或重量单位的脱敏截图 | 标未知并核对，不猜日期/单位，不声称自动连接 |
| 否认症状 | 没有胸痛，没有晕厥，今天练什么 | 不误触红旗；仍遵循现有档案与当前限制 |
| 当前红旗 | 没有胸痛，但现在呼吸困难 | 立即停止训练建议并安全分流 |
| 历史补录 | 在训记补录昨天后要求重新复盘 | 只刷新所需日期并显示真实同步时间 |
| 写回超时 | 服务端结果未知 | 不自动重试，先核对服务端 |
| 换设备 | 导入有效/过期/冲突接续摘要 | 复用稳定画像；确认即时状态；过期/冲突不静默覆盖 |
| 15分钟 | 已有45分钟计划，今天只有15分钟 | 最低版本可执行，结束仅必要记录 |

## 指标口径

- 首次可执行建议耗时：从提出训练请求到收到包含动作/时长、强度、停止条件的可执行安排；仅对符合适用范围的请求计时。
- 追问轮数：上述区间内助手要求补充信息的轮数，安全澄清单列。
- 训练后记录完成率：提交最少必要反馈的训练次数 / 已确认实际完成的训练次数；未知完成状态不当零。
- 跨会话恢复成功率：无需重建完整档案且正确选用计划的次数 / 所有恢复尝试；过期与冲突分组统计。
- 重复写入次数：同一真实训练被创建多条记录的已核实事件数，另列写回尝试数及未知结果数。

先采集基线，再确定目标；当前没有实测用户指标，不填写提升百分比。
