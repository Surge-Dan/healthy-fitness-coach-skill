# 视觉参考账本

视觉研究只提炼可迁移的设计方法，不复制具体作品、Logo、品牌字体或原构图。用户截图是灵感输入，不作为第三方素材发布。

## 已核查的公开方法

- 社交拼贴/故事卡：以1～3张锚点照片建立叙事，再用裁切、纸片、标签、箭头、时间戳和手写注释组织层级。
- 撕纸与材质：使用不规则边缘、纸张纤维、网点、复印颗粒和胶带关系，但装饰必须服务照片事实或训练数据。
- 编辑部版式：明确标题、数据、图表、注释和页脚的层级，避免每个区块都使用相同“标题+卡片”模板。
- 卡通/手绘转换：保留原照片作为事实层，派生层只生成不含文字和数字的线稿、色块、运动轨迹或符号。

## 与健身场景的独有转译

1. **训练事实层**：原图、真实日期、训练动作和数据由本地排版器保留，不能由图像模型重写。
2. **视觉DNA层**：从照片提取色板、明暗、纹理、边缘节奏、视觉重心和安全文字区，而不是只取平均颜色。
3. **运动母题层**：只从已观察到的器械、镜面、灯光、动作方向和训练数据生成轨迹、网点、肌群轮廓或器械符号。
4. **构图配方层**：单图使用原图×派生层、漫画分镜或双色小志；多图使用训练故事板；无图使用数据图谱、训练年轮或动作指纹。
5. **质量门禁**：检查比例、越界、文字安全区、中文字体、热力图端点对齐、图表可读性和数据溯源。
