# 训练现场辅助

## 当日状态检查

快速确认：今天是否有新红旗或急性外伤、睡眠与精力、目标部位不适、可用时间和器械。安全问题读取 `references/safety-screening.md`；普通波动不需要取消全部训练。需要结构化判断时，传入标准化的 `currentState`（保留 `safety.red_flags`/`safety.redFlags` 与 `symptoms`）与当前计划；数字字符串须可解析，否则先确认状态，不得按正常状态放行。计划压缩必须复用该计划对应训练日的 `minimum_version`，不要临时编造动作。

用交通灯表达：

- 绿灯（`proceed`）：状态接近常态，按计划执行；
- 黄灯（`regress`）：按固定优先级只改一个主变量：疼痛/不适优先换为更耐受的变式并观察 24～48 小时；训练日无法确认时先确认训练日；时间变少时只执行计划已有的 `minimum_version`；在无上述更高优先级问题时，疲劳高时减少组数或降低强度其一，单晚睡眠差优先降强度，不能据此判断过度训练。
- 红灯（`stop`）：安全红旗、急性严重外伤或症状快速恶化时，停止自动训练处方与最低任务，建议及时获得合适评估。

## 训练流程

### 1. 热身

1. 3～8 分钟轻度活动提高体温；
2. 对当天关键关节做少量动态准备；
3. 主动作从轻到重做 2～4 个递增热身组；
4. 热身组用于观察动作、速度、不适和当天负荷，不做到疲劳。

### 2. 选择重量

优先从用户上次记录推算，并用热身组修正。首个正式组结束后判断：

- 比目标 RIR 多 2 次以上：小幅加重或增加次数；
- 落在目标 RIR：保持；
- 少于目标 RIR、动作变形或速度骤降：减重；
- 出现不可接受不适：本次只选一个保守调整（减重、缩幅、减组或换动作），记录反应；若加重则停止相关动作。

### 3. 动作提示

每个动作只给 1～3 个与当前错误相关的提示。优先使用外部结果和稳定节奏，例如“脚掌压住地面”“把手柄拉向下胸”“让哑铃沿身体两侧下落”。不要一次罗列十条解剖细节。

动作标准以安全、可重复和目标刺激为准，不追求所有人相同的关节角度。不同身材、器械和舒适度允许合理变式。

### 4. 组间调整

- 复合动作通常休息约 2～3 分钟；
- 单关节或低疲劳动作通常约 1～2 分钟；
- 若下一组表现明显受呼吸影响，延长休息而不是强迫卡秒；
- 记录真实完成情况，不把临时降载视为失败。

## 替代动作逻辑

先保持训练目标，再替换具体动作：

- 深蹲不适：尝试箱式深蹲、分腿蹲、腿举或较小幅度；
- 髋铰链不适：尝试臀桥、髋推、拉力器拉穿或较轻罗马尼亚硬拉；
- 卧推不适：尝试哑铃中立握、俯卧撑、器械推胸或缩小幅度；
- 垂直拉条件不足：使用弹力带下拉、单臂划船或反向划船；
- 跳跃冲击不耐受：改为快走、踏步、单车或低冲击跟练。

不要用“护膝”“不伤腰”等绝对标签。说明替代动作为什么更符合当下耐受与设备条件。

## 最低有效版本

用户只有 10～20 分钟时：

1. 选一个下肢动作；
2. 选一个推；
3. 选一个拉；
4. 每个 1～3 组，保留约 2～3 RIR；
5. 有余力再补短时心肺或核心。

低状态时优先维持习惯和技术暴露，不用高强度间歇作为惩罚。若状态引擎输出 `stop`，不执行本节最低版本。

## 结束记录

使用 `assets/workout-log-template.md` 记录完成情况、RPE 或 RIR，以及疼痛或有氧时长中的相关项；阻力训练同时记录动作、负重、次数和组数。下一次建议必须优先读取真实记录，而非重新猜测。
