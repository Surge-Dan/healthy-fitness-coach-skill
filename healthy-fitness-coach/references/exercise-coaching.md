# 训练现场辅助

## 当日状态检查

快速确认：今天是否有新红旗或急性外伤、睡眠与精力、目标部位不适、可用时间和器械。安全问题读取 `references/safety-screening.md`；普通波动不需要取消全部训练。

用交通灯表达：

- 绿灯：状态接近常态，按计划执行；
- 黄灯：睡眠不足、压力高、轻度不适或热身表现偏差，减少重量/组数/幅度；
- 红灯：安全红旗、急性严重外伤或症状快速恶化，停止训练处方并转介。

## 训练流程

### 1. 热身

1. 3～8 分钟轻度活动提高体温；
2. 对当天关键关节做少量动态准备；
3. 主动作从轻到重做 2～4 个递增热身组；
4. 热身组用于观察动作、速度、不适和当天负荷，不做到疲劳。

### 2. 选择重量

优先从用户上次记录推算，并用热身组修正。首个正式组结束后判断：

- 比目标 RIR 多 2 次以上：小幅加重或增加次数；
- 落在目标 RIR：保持；
- 少于目标 RIR、动作变形或速度骤降：减重；
- 出现不可接受不适：按减重、缩幅、减组、换动作、停止的顺序处理。

### 3. 动作提示

每个动作只给 1～3 个与当前错误相关的提示。优先使用外部结果和稳定节奏，例如“脚掌压住地面”“把手柄拉向下胸”“让哑铃沿身体两侧下落”。不要一次罗列十条解剖细节。

动作标准以安全、可重复和目标刺激为准，不追求所有人相同的关节角度。不同身材、器械和舒适度允许合理变式。

### 4. 组间调整

- 复合动作通常休息约 2～3 分钟；
- 单关节或低疲劳动作通常约 1～2 分钟；
- 若下一组表现明显受呼吸影响，延长休息而不是强迫卡秒；
- 记录真实完成情况，不把临时降载视为失败。

## 替代动作逻辑

先保持训练目标，再替换具体动作：

- 深蹲不适：尝试箱式深蹲、分腿蹲、腿举或较小幅度；
- 髋铰链不适：尝试臀桥、髋推、拉力器拉穿或较轻罗马尼亚硬拉；
- 卧推不适：尝试哑铃中立握、俯卧撑、器械推胸或缩小幅度；
- 垂直拉条件不足：使用弹力带下拉、单臂划船或反向划船；
- 跳跃冲击不耐受：改为快走、踏步、单车或低冲击跟练。

不要用“护膝”“不伤腰”等绝对标签。说明替代动作为什么更符合当下耐受与设备条件。

## 最低有效版本

用户只有 10～20 分钟时：

1. 选一个下肢动作；
2. 选一个推；
3. 选一个拉；
4. 每个 1～3 组，保留约 2～3 RIR；
5. 有余力再补短时心肺或核心。

低状态时优先维持习惯和技术暴露，不用高强度间歇作为惩罚。

## 结束记录

使用 `assets/workout-log-template.md` 记录动作、负重、次数、组数、RIR、疼痛、完成率和一句主观备注。下一次建议必须优先读取真实记录，而非重新猜测。
