# 人物问题证据门

这份协议用于用户点名询问某位健身创作者、教练、研究者或机构时。人物卡是可复用原则索引，不是对任何人的全部公开内容、私生活或最新观点的穷尽式数据库。

## 三种结果

### 可回答：卡片范围内

当问题只要求解释卡片已记录的训练原则、执行方法、适用条件或已记录的风险时，可以回答。只使用卡片中的来源映射和摘要，不编造原话、课表、资质或个人经历。涉及因果关系时，仍按 `evidence-rules.md` 的证据层级裁决。

### 需要检索：卡片不足或问题具有时效性

下列情况必须先使用当前可用的公开检索工具核查，或请用户提供原文、视频、截图：最新观点、完整生涯、个人经历、资质、商业合作、某条视频的逐句立场、卡片未覆盖的具体动作/营养/伤痛问题，以及“他是否说过……”这类原话问题。检索不到时明确写“当前资料不足”，不能用相邻原则代替答案。

### 未知人物：没有可靠来源卡

人物不在 `creator-cards.md`，或只有不可访问、无法核验的转述时，不得凭名字或搜索摘要推断其观点。可以回答通用健康建议，但要明确这不是该人物立场；用户提供可访问来源后再建立临时证据卡。

## 来源与表达

每条人物结论先标记来源类型：

- **直接陈述**：创作者本人官网、公开文章、公开演讲或可核验视频文本中的明确表达。
- **二手转述**：团队页面、访谈报道、研究解读或平台简介；只能说明“来源这样概括”，不能升级为本人原话。
- **推断**：根据多条来源归纳出的可能原则；必须标为推断，附适用条件与反证可能。

不把人物名气当作证据；不要因为粉丝量、外形、头衔或商业成绩提高证据等级。来源卡中出现的商业产品、课程或赞助，只作为利益披露，不自动成为推荐。

## 回答模板

人物问题按以下顺序组织：

1. **问题范围**：卡片支持、需要检索，或未知人物。
2. **来源事实**：用自己的话概括已核验材料，并标直接陈述/二手转述/推断。
3. **适用边界**：目标、训练阶段、器械、恢复和安全条件。
4. **与更高证据的关系**：若与指南、研究或用户反馈冲突，说明裁决理由。
5. **对用户的可执行转译**：只给符合用户目标和安全筛查的行动，不复制固定课表。
6. **不确定性与下一步**：资料不足时给出需要补充的链接、截图或问题。

## 研究边界

小红书、Instagram等登录受限平台只能在用户授权浏览器或提供截图/文本时使用。不得绕过登录、验证码、robots或反爬限制；不可访问不等于已完成蒸馏。研究结果应更新 `research-ledger.md` 的复核日期和访问状态，而不是把运行时抓取内容写入个人报告或仓库。
